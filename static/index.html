        Where do I get these?
        • Anthropic: console.anthropic.com → API keys. Powers scoring, tailoring and cover letters.
        • JSearch: app.openwebninja.com → free plan (no card) → enable JSearch → copy your API key. This is how Indeed and ZipRecruiter postings come in. A JSearch key from RapidAPI works too.
        • USAJOBS (optional): developer.usajobs.gov → request an API key.
        • Remotive / Remote OK: no key needed.

        Gmail

        One-time Google setup (about 5 minutes)

        Google only lets apps read Gmail through an OAuth client that you own. It's free and only you will use it.

        1. Go to console.cloud.google.com and create a project, for example "JobScout".
        2. APIs & Services → Library: search for Gmail API and click Enable.
        3. Google Auth Platform (or OAuth consent screen) → Get started. App name: JobScout. Audience: External. Use your own email for the contact fields.
        4. Audience → Test users → Add users: add your Gmail address.
        5. Clients → Create client. Application type: Desktop app. Then Download JSON.
        6. Choose that JSON file in Step 1 above (it saves right away), then click Connect Gmail. Google's sign-in opens in your browser. Sign in as usual (SSO and 2-step verification work). Google will warn that the app isn't verified, which is expected for your own private app: click Continue.

        While the Google app is in "Testing" mode, Google expires the sign-in about every 7 days. JobScout will ask you to click Connect again when that happens. To avoid it, set the app to "In production" under Audience. That needs no review for personal use, but Google will keep showing the unverified-app warning.
